# peacock-CRM

All application code lives in **[`Peacock one/`](./Peacock%20one/)** — the single
project root for Peacock One (frontend, backend, AI connector plugins,
SEO/AEO/GEO/AI-visibility engines, agents, experts, publishing connectors,
database migrations, scripts, docs, and tests).

```bash
cd "Peacock one"
cp .env.example .env
docker compose up --build
```

See [`Peacock one/README.md`](./Peacock%20one/README.md) for local development,
tests, and architecture.
