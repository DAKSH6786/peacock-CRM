# peacock-CRM

All application code lives in **[`Peacock/`](./Peacock/)** — the single
project root for Peacock One (frontend, backend, AI connector plugins,
SEO/AEO/GEO/AI-visibility engines, agents, experts, publishing connectors,
database migrations, scripts, docs, and tests).

```bash
cd Peacock
npm install
npm run dev
```

See [`Peacock/README.md`](./Peacock/README.md) for local development,
tests, and architecture.
